# B4P-hsCRP-reference-curves-analysis
This repository contains the code and material to reproduce the results of the manuscript "International High-sensitivity C-reactive protein reference curves from infancy to young adulthood: findings from the Biomarkers4Pediatrics Collaboration". 

## Project aim

The project aims to develop age- and sex-specific reference curves for high-sensitivity C-reactive protein (hs-CRP) in children, adolescents, and young adults using pooled data from Biomarkers4Pediatrics Collaboration.

## Repository structure

- `R/`: Main analysis scripts
- `functions/`: Helper functions
- `outputs/`: Figures and tables generated by the analysis
- `docs/`: Notes and documentation

## Data privacy

Individual-level data are not stored in this repository. All data files and intermediate datasets are excluded via `.gitignore`.

## Main analysis steps

1. Data preparation and harmonization
2. Descriptive analysis
3. Percentile curve generation
4. Elevated hs-CRP percentages comparison
5. Sensitivity analysis of measurement methods
6. Leave-one-study-out cross validation(LOSO-CV)
